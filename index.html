F3X Build
Storage

A companion service for an independent Roblox Studio import/export plugin. The plugin handles build uploads and downloads from inside Roblox Studio; this website does not expose a public build directory.

Development disclosure

This project was created with substantial assistance from AI tools, using an AI-assisted development approach sometimes called “vibe-coding.” The project direction, requirements, and decisions are human-directed. AI assistance is not a security audit or a guarantee that every feature is bug-free.

How it works

  1. Select a build in Roblox Studio and press Export.
  2. Keep the four-character code returned by the plugin.
  3. Enter that code in the plugin and press Import whenever you want the build back.

Builds are intended to be stored indefinitely for now. Their creation date and last-accessed date are retained so an expiration policy can be enabled later if needed.

Access requirements

Import and export requests are checked by the service. Users must be members of the required Roblox group. Export requests have a one-second cooldown, with a temporary pause for repeated rapid attempts.

Build codes are short, private retrieval keys. Do not share a code unless you want someone else to be able to import that build.
